# QuickStart

## Short Description
A simple HTML/CSS project using Bootstrap 5 for quick web development prototyping.

## Brief Details
- **HTML File**: Quickstart.html - The main webpage structure.
- **CSS File**: Quickstart.css - Custom styles for the project.
- **Bootstrap**: Includes Bootstrap 5.0.2 distribution for responsive design and components.
- **Images**: img/ folder contains project images.

## Usage
Open `Quickstart.html` in a web browser to view the page. No server required for static content.
